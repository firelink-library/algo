Kotlin é a linguagem oficial para desenvolvimento Android desde 2017, quando o Google a adotou como primeira opção. Ela roda na JVM, é totalmente interoperável com Java e foi criada para ser mais concisa, segura e expressiva. Neste material vamos aprender a desenvolver aplicativos Android nativos com Kotlin.

## 1. Desenvolvimento Nativo

Apps nativos rodam direto no sistema operacional, sem uma camada intermediária de tradução. Isso faz diferença em listas longas, animações complexas, câmera, mapas e jogos — qualquer coisa que exija processamento intenso.

```
Cross-platform:   seu código → bridge/runtime → Android
Nativo:           seu código → Android  (direto)
```

**Acesso completo às APIs do Android**

O Android lança APIs novas a cada versão — notificações, widgets, câmera, Bluetooth, NFC, sensores, etc. No nativo, você usa essas APIs no dia do lançamento. No cross-platform, você espera a biblioteca de terceiros dar suporte.

```kotlin
// No nativo você tem acesso a qualquer API do Android diretamente
val camera = getSystemService(CameraManager::class.java)
val vibrator = getSystemService(Vibrator::class.java)
val biometricPrompt = BiometricPrompt(this, executor, callback)
```

**Experiência do usuário consistente**

Apps nativos respeitam automaticamente as diretrizes de cada plataforma — animações, gestos, fontes, tamanhos de toque. O resultado é um app que "parece Android", sem precisar simular comportamentos.

**Android tem mais de 70% do mercado mobile mundial**

Isso significa que dominar Kotlin para Android te dá acesso imediato a uma base enorme de usuários. Somado ao fato de que Kotlin é uma linguagem moderna com excelente suporte do Google, é uma das escolhas mais sólidas para quem quer trabalhar com mobile hoje.

## 2. Por que Kotlin para Android?

Kotlin traz algumas vantagens em relação ao Java no desenvolvimento Android:

- **Null Safety**: o compilador impede que você acesse variáveis nulas acidentalmente, eliminando `NullPointerException` em tempo de compilação.
- **Concisão**: menos código para fazer a mesma coisa — data classes, lambdas, extension functions.
- **Coroutines**: forma elegante e eficiente de trabalhar com código assíncrono (chamadas de rede, banco de dados).
- **Interoperabilidade**: você pode usar qualquer biblioteca Java existente dentro de um projeto Kotlin.


## 3. Sintaxe Básica do Kotlin

Antes de avançar, vale revisar os principais elementos da linguagem.

### 3.1 Variáveis

```kotlin
val nome = "Android"       // imutável (não pode ser reatribuída)
var contador = 0           // mutável
var texto: String? = null  // nullable — pode ser null
```

### 3.2 Funções

```kotlin
fun somar(a: Int, b: Int): Int {
    return a + b
}

// versão reduzida (expression body)
fun somar(a: Int, b: Int) = a + b
```

### 3.3 Null Safety

```kotlin
var nome: String? = null

// forma segura de acessar
val tamanho = nome?.length  // retorna null se nome for null

// operador Elvis: valor padrão quando null
val tamanho = nome?.length ?: 0
```

### 3.4 Classes e Data Classes

```kotlin
// classe normal
class Pessoa(val nome: String, var idade: Int)

// data class: gera equals, hashCode, toString e copy automaticamente
data class Produto(val id: Int, val nome: String, val preco: Double)

val produto = Produto(1, "Café", 12.90)
val copia = produto.copy(preco = 10.00)
```

### 3.5 When (substitui o switch)

```kotlin
val nota = 8

val conceito = when {
    nota >= 9 -> "A"
    nota >= 7 -> "B"
    nota >= 5 -> "C"
    else      -> "D"
}
```

### 3.6 Lambdas e Higher-Order Functions

```kotlin
val numeros = listOf(1, 2, 3, 4, 5)

val pares = numeros.filter { it % 2 == 0 }   // [2, 4]
val dobros = numeros.map { it * 2 }            // [2, 4, 6, 8, 10]
val soma = numeros.reduce { acc, n -> acc + n } // 15
```
